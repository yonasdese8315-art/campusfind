# CampusFind

## University Lost and Found Management System

CampusFind is a web-based Lost and Found Management System designed to help students and staff report, search, track, and recover lost items within the university campus.

### Motto

**Find it. Report it. Reclaim it.**

## Project Objectives

- Provide a centralized platform for reporting lost items.
- Enable users to report found items.
- Simplify item searching and tracking.
- Improve item recovery efficiency.
- Maintain secure records of lost and found items.

## Key Features

### User Features

- User Registration and Login
- Report Lost Items
- Report Found Items
- Search and Filter Items
- Submit Ownership Claims
- Track Claim Status
- Manage User Profile

### Administrator Features

- Manage Users
- Manage Lost Item Reports
- Manage Found Item Reports
- Verify Claims
- Approve or Reject Claims
- Generate Reports
- Monitor System Activities
